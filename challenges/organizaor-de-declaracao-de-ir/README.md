# 📑 Tax Data Aggregator: Organizador de Declaração de IR

![Excel](https://img.shields.io/badge/Microsoft_Excel-217346?style=for-the-badge&logo=microsoft-excel&logoColor=white)

## 🌟 Visão Geral

Este projeto foi desenvolvido como um desafio prático pela **DIO**, com o objetivo de criar uma ferramenta robusta e amigável para a organização de dados fiscais. A planilha funciona como um **hub centralizador**, onde o contribuinte pode reunir informações de diferentes fontes (bancos, holerites e dados pessoais) em um único local, facilitando o preenchimento da declaração anual de Imposto de Renda.

O foco aqui não é apenas o registro, mas a **integridade dos dados** através de validações e uma navegação intuitiva.

---

## 🚀 Funcionalidades Principais

* Cadastro detalhado do titular com campos validados para evitar erros em dados críticos como CPF e Título de Eleitor.
* Gestão de rendimentos bancários com suporte a múltiplos bancos (Santander, C6 Bank, Inter, etc.) e controle de anexos.
* Estrutura para acompanhamento mensal de entradas e notas bancárias.
* Tabela de apoio integrada com códigos de compensação de mais de 40 bancos brasileiros.

---

## 📁 Estrutura da Ferramenta

1.  **Módulo Titular:** Dados pessoais e histórico de alterações em relação à entrega anterior.
2.  **Módulo de Informes:** Registro analítico de valores atuais por instituição financeira.
3.  **Módulo de Notas:** Lançamento de entradas mensais por categoria.
4.  **Módulo de Referência (TBLs):** Base de dados relacional com códigos bancários para automação de preenchimento.
